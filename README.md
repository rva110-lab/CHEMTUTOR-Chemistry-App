# CHEM/TUTOR - Chemistry Learning App

An interactive chemistry tutoring app designed for 11th & 12th grade CBSE/NCERT students.

## Features

•⁠  ⁠*17 Reactions* - Detailed explanations of chemical reactions with mechanisms
•⁠  ⁠*28 Dictionary Entries* - Chemistry glossary with key terms and definitions  
•⁠  ⁠*9 Worked Numericals* - Step-by-step solutions to chemistry problems
•⁠  ⁠*Interactive Study Tools* - Grade 11 & 12 tools, Quick Quiz, Flashcards
•⁠  ⁠*Progress Tracking* - Monitor your learning journey

## Topics Covered

•⁠  ⁠Thermodynamics
•⁠  ⁠Chemical Kinetics
•⁠  ⁠Equilibrium
•⁠  ⁠And more CBSE/NCERT topics
